विघ्नहर्ता मेडिकल - Android APK प्रारंभिक प्रोजेक्ट (APK नाही)

हा सध्याच्या GitHub Pages वेबसाइटचा Android WebView wrapper प्रोजेक्ट आहे.
महत्त्वाचे: याला अंतिम ऑनलाइन+ऑफलाइन APK समजू नका.

उर्वरित काम:
1. Android SDK + Gradle असलेल्या वातावरणात बिल्ड.
2. Firebase login, camera/gallery upload, QR/barcode scanner, file download तपासणे व Android permissions/file chooser/download manager जोडणे.
3. पूर्ण ऑफलाइन वापरासाठी वेबसाइटमध्ये service worker, local data queue, safe sync, conflict handling आणि Firebase sync चाचणी.
4. APK signing, install testing, old-data regression testing.

सध्याच्या प्रोजेक्टमध्ये वेबसाइट लोड होते; इंटरनेट नसताना संपूर्ण अॅप चालेल याची हमी नाही.
मूळ वेबसाइट किंवा Firebase डेटा बदललेला नाही.
